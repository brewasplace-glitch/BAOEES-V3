# Phoenix Development Kit (PDK) v1.0

## Doel

De PDK is de interne ontwikkeltooling van Project Phoenix.

## Onderdelen

- Suite Generator
- Module Generator
- Test Generator
- Specification Validator
- Release Builder

## Eerste bootstrap

PDK v1.0 maakt alvast de eerste Architectural Suite structuur aan met:

- Project Intake
- Programma van Eisen
- Ruimtestaat
- Plattegrondgenerator
