# BB35 Pilot 1 — Professional Evidence Replacement Programme v2.2.0

This module creates six controlled professional evidence workpacks for
REQ-102, REQ-103, REQ-104, REQ-105, REQ-106 and REQ-108.

REQ-107 remains closed through project-leader approval and is excluded from
replacement. The programme enables adviser issue and evidence intake, but does
not accept or close any professional evidence automatically. Final permit-ready
generation and BB36 production release remain locked until all six evidence
packages pass validation and closure.
