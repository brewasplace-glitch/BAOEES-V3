# BB35 Pilot 1 — Scope Decision B v1.1.0

## Authoritative project scope

The Moskee Bunschoten pilot shall use:

- extension width: 7.00 m;
- extension depth: 10.00 m;
- footprint: 70.00 m²;
- extension storeys: 2;
- gross extension area: approximately 140.00 m².

All previous references to an extension of approximately 20 m² are superseded.

## Mandatory downstream application

The selected scope is the controlling basis for:

- 3D model and impressions;
- architectural and building drawings;
- structural model, calculations and report;
- permit, BOPA/ETFAL and participation documents;
- parking and traffic assessment;
- AERIUS assessment;
- technical specification and specification drawings;
- quantities, cost calculation and material schedules;
- site plan and project dossier.
