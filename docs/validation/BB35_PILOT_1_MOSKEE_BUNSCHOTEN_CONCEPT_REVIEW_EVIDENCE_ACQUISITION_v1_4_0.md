# BB35 Pilot 1 - Concept Review & Evidence Acquisition v1.4.0

## Purpose

This phase reviews the deterministic concept package and converts every open
technical dependency into a controlled evidence-acquisition request.

## Review outcome

Expected status:

`CONCEPT_REVIEW_COMPLETE_EVIDENCE_ACQUISITION_OPEN`

The concept package is accepted for continued concept coordination with explicit
conditions. It is not accepted for construction, procurement, permit submission
or commercial production release.

## Evidence packages

Eight controlled request packages are generated:

1. REQ-101 - original 19-page existing-building drawings.
2. REQ-102 - cadastral DWG and surveyed site base.
3. REQ-103 - signed structural survey.
4. REQ-104 - geotechnical investigation and foundation advice.
5. REQ-105 - coordinated Bbl, fire, occupancy, material and MEP assumptions.
6. REQ-106 - parking field counts and public/private use evidence.
7. REQ-107 - agreed occupancy and operational programme.
8. REQ-108 - AERIUS construction and operational activity data.

Each package contains a request record, request letter, checklist, professional
verification template, submission instructions and a PDF request sheet.

## Acceptance policy

Original files and professional verification are required. Offer letters,
references, screenshots and summaries do not replace final technical evidence.

Final generation remains blocked and BB36 remains locked.
