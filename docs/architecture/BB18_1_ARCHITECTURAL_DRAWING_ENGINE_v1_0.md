# BB18.1 — Architectural Drawing Engine v1.0.0

BB18.1 creates a deterministic architectural drawing package from the canonical
BB16 building model. It generates a drawing index, one plan per level, four
elevations, two sections and a schedule sheet. The first export formats are a
machine-readable JSON manifest and a dependency-free SVG concept plan.

The v1.0 output is for concept design and multidisciplinary coordination. It is
not automatically certified for permit submission, construction or legal
compliance. Later waves will add dimension chains, title blocks, sheet layouts,
DXF/PDF writers, revision clouds and jurisdiction-specific drawing sets.
