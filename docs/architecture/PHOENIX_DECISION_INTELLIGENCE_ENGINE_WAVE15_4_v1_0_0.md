# Phoenix Variant Ranking & Decision Intelligence Engine — Wave 15.4 v1.0.0

Deterministic MCDA using weighted sum, weighted product, TOPSIS, Pareto analysis and one-at-a-time weight sensitivity. Inputs are approved criteria, weights and variant metrics from Waves 15.1–15.3. Outputs include ranking, recommendation, alternatives, Pareto front, sensitivity stability, confidence and SHA-256 evidence. Decision support only; multidisciplinary review remains mandatory.
