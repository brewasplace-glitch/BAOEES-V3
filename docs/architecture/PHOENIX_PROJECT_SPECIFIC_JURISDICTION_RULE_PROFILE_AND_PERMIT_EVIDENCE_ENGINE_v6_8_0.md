# Phoenix Project-Specific Jurisdiction Rule Profile and Permit Evidence Engine v6.8.0

This engine converts project-specific legal/technical sources into a traceable
permit-evidence model.

It does not invent statutory thresholds. A project profile must explicitly
provide jurisdiction identity, authority, source/version/effective-date data,
rule clauses, evidence links and professional review.

Permit-ready unlock requires all mandatory release conditions to be true.
Execution-ready remains locked pending final design and professional approval.
