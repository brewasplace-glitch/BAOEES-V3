# Phoenix Project Generator (PPG) v1.0

PPG is the official entry point for the Phoenix command:

> Ontwerp een appartementencomplex op deze locatie.

PPG v1.0 converts one project brief into exactly ten deterministic concept
variants. Each variant contains a distinct archetype, massing concept,
circulation concept, structural concept, provisional foundation strategy,
parking strategy, sustainability strategy, assumptions, risks, evidence,
scores and a unique fingerprint.

The ten variants are ranked and exposed as a one-by-one presentation queue.

Selection modes:

1. automatic selection of the highest-ranked concept;
2. user selection by variant ID;
3. later integration of an externally supplied design.

PPG v1.0 does not claim permit-ready drawings, final costs, verified foundation
design or code-compliant engineering. Those outputs remain responsibilities of
the downstream GIS, Geotechnical, Structural, BIM, Permit, Cost and Planning
engines.

The selected PPG variant becomes the controlled input for Phoenix Autonomous
Project Delivery and the central Digital Twin.
