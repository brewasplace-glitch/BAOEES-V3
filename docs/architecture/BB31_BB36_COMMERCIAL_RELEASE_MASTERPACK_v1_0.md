# BB31-BB36 — Commercial Release Masterpack v1.0.0

## BB31

Commercial product shell, project intake contract and the command
`GENERATE_FULL_BUILDING_DESIGN_PACKAGE`.

## BB32

Adapter-based orchestration of the nine commercial outputs:

1. 3D impression;
2. structural calculations;
3. structural report;
4. building drawings;
5. technical specification;
6. specification drawings;
7. cost calculation;
8. material schedules;
9. site plan.

## BB33

Role-based permissions, SHA-256 integrity evidence, chained audit events and
mandatory backup/restore testing. This foundation does not claim encrypted
storage by itself.

## BB34

Release Candidate gate for semantic versioning, regression, clean installation,
updates, migrations, rollback, licensing policy and user documentation.

## BB35

Real-project validation gate. At least two real projects must pass independent
professional review, clean installation, reproducibility and end-to-end
generation. Synthetic self-tests never satisfy this gate.

Recommended pilots:

- Moskee Bunschoten;
- Plutostraat Paramaribo.

## BB36

Commercial production release gate. It remains locked until BB34, BB35 and
BB33 pass and production documentation and support plans exist.

Installing this masterpack therefore installs the complete release framework,
but does not falsely declare Phoenix commercially proven before the pilots.
