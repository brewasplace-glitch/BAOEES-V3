# Phoenix Execution Drawing, Detail Library, Specification and Construction Release Engine v7.0.0

v7.0.0 adds the controlled transition from permit dossier to construction release.

Core capabilities:
- architectural detail library;
- project detail register;
- execution drawing/document register;
- dimension/completeness flags;
- material specification register;
- product requirement register;
- constructability checks;
- revision/status control;
- execution release matrix;
- Digital Twin execution-release writeback;
- SHA-256 artifact manifest.

Automatic construction release is disabled. Execution-ready unlock requires
the upstream permit dossier gate, complete and coordinated mandatory details,
current approved construction documents, approved materials/products,
passed constructability checks with evidence, and professional release.
