# BB17.1 — Codepack Governance & Source Registry v1.0.0

BB17.1 governs all rulepacks used by the BB17 Building Code Engine. It
records jurisdiction, publication metadata, edition, effective period,
source-verification state, review evidence, activation state, rights
metadata, supersession and rollback candidates.

An active regulatory codepack must be validated, reviewed and supported by
verified source metadata with an effective date. Draft jurisdiction
foundations may register identified sources without claiming legal
compliance.
