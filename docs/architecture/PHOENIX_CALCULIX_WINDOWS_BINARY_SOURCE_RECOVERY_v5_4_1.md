# CalculiX Windows Binary Source Recovery v5.4.1

Uses the official MSYS2 MinGW64 package `mingw-w64-x86_64-calculix-ccx`, installed at `C:\msys64\mingw64\bin\ccx.exe`. The installer verifies the MSYS2 installer checksum, package version and package inventory, then runs the real C3D8 DAT/FRD acceptance model. No third-party binaries are committed to Git.
