# BB19 — Structural Design Engine v1.0.0

BB19 derives a preliminary structural model from BB16 building elements. It
selects foundations, columns, beams, walls, slabs, roofs and stairs; creates
concept load cases and combinations; registers foundation interfaces; validates
the model; and exports controlled analysis handoffs for OpenSeesPy, CalculiX and
SCIA Engineer.

All load factors in v1.0 are placeholders until an approved BB17.4 jurisdiction
rulepack and project-specific actions are applied. Results are non-certifying
and require geotechnical, code and professional engineering review.
