# Phoenix Architectural Compliance, Fire Safety, Accessibility and Building Physics Engine v6.7.0

Generic jurisdiction-aware compliance layer for use functions, fire compartments, escape routes, accessibility, daylight, ventilation, thermal envelope and moisture evidence. The supplied generic rule profile is intentionally unverified and contains no invented legal thresholds. Permit-ready release requires a verified project-specific rule profile, all mandatory checks assessable and passing, and professional legal/technical approval.
