# Phoenix Core v2.0 — BB6 Blender Visualization Engine v1.0.0

## Purpose

BB6 upgrades the Blender foundation adapter to an operational visualization
engine for scene ingestion, material assignment, lighting, camera setup,
still-image rendering, animation rendering and scene export.

## Delivered

- Blender executable and version detection;
- background execution with factory startup;
- JSON worker protocol;
- OBJ, glTF, GLB, STL, FBX and BLEND ingestion;
- material assignment;
- camera and lighting configuration;
- still renders;
- animation and walkthrough rendering;
- BLEND scene saving;
- OBJ, glTF, GLB and STL export;
- scene inspection metadata;
- bounded timeouts;
- SHA-256 output evidence;
- Digital Twin visualization readiness metadata.

## Operational boundary

The automated tests use a deterministic simulated Blender runner. Real
visualization requires Blender on the target machine.
