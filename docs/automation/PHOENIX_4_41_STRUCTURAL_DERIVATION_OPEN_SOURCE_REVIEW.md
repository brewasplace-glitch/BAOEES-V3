# Open-source review

Primary solver target: OpenSees (official UC Berkeley source; BSD-3-Clause reference in official build configuration).
Fallback/cross-check: CalculiX (upstream Guido Dhondt/Klaus Wittig; GPL-2.0).

Eurocodes are used only as a preliminary technical reference family. No claim is made that a Dutch National Annex or a specific Eurocode edition is legally applicable in Suriname. Wind is a 30/35/40 m/s sensitivity sweep only, not a selected legal design wind speed.
