# PROJECT PHOENIX R9.4 — Normative Applicability & Stability Design-Basis Qualification Masterpack v1.0

## Purpose
R9.4 starts only after R9.3 has produced technical evidence for all nine v8.6 global-stability checks with no analysis-required checks remaining. It does not add another structural analysis engine. It converts the remaining blocker into an explicit applicability/design-basis contract.

## Public source registry
R9.4 ships a dated public metadata registry (2026-08-10) containing only document identity and broad scope statements for:
- NEN-EN 1990-1:2025+A1:2026 en — current basis of structural/geotechnical design; public scope includes safety, serviceability, robustness and durability.
- NEN-EN 1991-1-7:2026 en — final accidental-actions standard; public scope includes tying systems, key members and risk assessment.
- NEN-EN 1992-1-1 Dutch National Annex including A2:2025 — current Dutch NA published 2025-05-01; exact nationally determined parameter values are not embedded.
- European Commission JRC Eurocode 8 scope — seismic design applies to buildings/civil works in seismic regions.

## Jurisdiction rule
Project jurisdiction is Suriname / Paramaribo. Legal applicability of Dutch/European standards in Suriname remains NOT VERIFIED. The existing Eurocode-2-based basis may be used only as an ENGINEERING DESIGN CANDIDATE with professional structural review.

## Check classification
Each of the nine checks is classified as APPLICABLE, SUPPLEMENTAL_ENGINEERING_POLICY or NOT_APPLICABLE only through explicit project input. Public metadata alone never supplies the final acceptance limit. Seismic-style storey/torsion checks additionally require a traceable seismic-applicability decision.

## Existing v8.6 gate is preserved
NOT_APPLICABLE does not silently waive the mandatory v8.6 check set. If a check is excluded from project scope, professional review or a future explicit scope-control change is required. R9.4 will not weaken v8.6 to force a pass.

## Residual-capacity safety
R8/R9.3 weak-storey capacity remains a screening proxy. R9.3 alternate-path evidence remains topology plus capacity-reserve screening; it is not promoted into redistributed nonlinear member-removal proof. An independently reviewed alternate-path verification reference is required before R9.4 can form that v8.6 check.

## Release controls
Automatic code-compliance claim: disabled. Automatic structural/robustness approval: disabled. Professional structural review: required. For-construction / production release: LOCKED.
