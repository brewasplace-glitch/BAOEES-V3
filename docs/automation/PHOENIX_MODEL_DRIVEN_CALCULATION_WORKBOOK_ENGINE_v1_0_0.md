# Project Phoenix — Model-Driven Calculation Workbook Engine v1.0.0

This engine converts the central geometric project model and the BB35 concept
simulation inputs into traceable calculation sheets.

Outputs include a 13-sheet XLSX workbook, a PDF calculation dossier, an HTML
dashboard, detailed CSV sheets, formula/input/traceability registers, QA checks,
checksums and a canonical issue package.

The results remain concept calculations. They are not professional structural,
geotechnical, fire-safety, ventilation, parking or AERIUS conclusions.
