## v1.1 live cross-gate diagnosis repair

The read-only live diagnostic proved that the A+B methodology layer reached R9.5 correctly for the five
non-seismic checks, but Package B criteria did not enter the merged R9.5 input. The merged input contained
`APPLICABLE` and accepted methodology, yet all three Package B numerical criteria and their traceability
remained `null`.

Root cause: `apply_package_b_traceability_to_r9_5_required_input_document()` required a top-level
`project_id`. The real R9.5 `required_input_template` / runtime input does not necessarily contain that
top-level field, so the function returned unchanged before adding the Package B source record and criteria.

v1.1 changes that guard safely:
- a present project id that mismatches the Package B registry still fails closed by returning unchanged;
- if the top-level project id is absent but the R9.5 decision-input section is present, the known project-
  scoped Package B registry may be applied;
- a document without the R9.5 decision-input section is still ignored.

No criterion, source, review or applicability decision is invented by this repair.
