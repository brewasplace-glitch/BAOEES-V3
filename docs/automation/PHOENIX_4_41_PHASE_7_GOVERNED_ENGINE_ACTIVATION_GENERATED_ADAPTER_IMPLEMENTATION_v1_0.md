# PROJECT PHOENIX 4.41 — FASE 7 Governed Engine Activation + Generated Adapter Implementation v1.0

FASE 7 converts a signed FASE-6 onboarding proposal into an integrity-bound activation transaction and exact repository activation bundle. Candidate code is not executed during validation. Generated adapter source is AST/contract checked, cryptographically bound, and staged outside the repository.

Actual repository activation requires a separate explicit human approval, an exact implementation SHA256 approval set, a verified full backup, clean/synced baseline, Universal Autonomy Gateway permit, exact-scope checks, regressions, normal commit/push and remote race guard.

Central policy DENY is never weakened automatically. Mutating future engine candidates remain ineligible when their FASE-6 policy coverage contains DENY. Interrupted activation is marked RECOVERY_REQUIRED and is never auto-replayed.
