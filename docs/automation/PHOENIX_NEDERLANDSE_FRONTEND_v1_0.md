# Phoenix Nederlandse Frontend v1.0

Phoenix toont standaard Nederlands aan de gebruiker. De technische backend-contracten blijven Engels.

Vertaald in de frontend zijn onder andere statussen, modals, navigatietermen en blocker-redenen. Technische JSON in `pre`/`code` blijft ongewijzigd.

Niet gewijzigd: API-routes, JSON-sleutels, `workflow_id`, `session_id`, `capability_id`, Engelse backend-statuscodes en exitcodes.

De localizer gebruikt geen polling; hij reageert alleen op echte DOM-wijzigingen.
