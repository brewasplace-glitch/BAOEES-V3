# Project Phoenix 4.41 — Phase 19

## Official Start Screen to Integrated Project Orchestration Bridge v1.0

Phase 19 connects the official `/start-v3/` project-start action to the governed
Phase-18 integrated project orchestration contract. It preserves the existing
intake and upload workflow, translates the selected project type, workflow mode,
brief and requested outputs, and displays all fifteen project stages.

The bridge does not create fictional variants, calculations, drawings, prices,
evidence or releases. Missing structured location data, verified discipline
inputs, five real variants or SHA-bound stage evidence remain visible blockers.
The fourteen engineering disciplines remain coordinated through the shared
Phoenix Digital Twin. Professional release always remains a human-controlled
boundary.

Autonomy mode mapping:

- manual → `LEVEL_0_MANUAL`
- guided → `LEVEL_2_SEMI_AUTONOMOUS`
- autonomous → `LEVEL_3_GOVERNED_AUTONOMOUS_TASK`

Runtime records are stored under
`outputs/runtime/phase19_start_screen_bridge/` and can be retrieved by their
content-derived Phase-19 run identifier.
