# Project Phoenix Central Geometric Project Model Engine v1.0.0

This engine establishes one deterministic geometry source for BB35 Pilot 1. It contains the existing building, the 7 x 10 metre two-storey extension, slabs, roofs, walls, spaces, stair, doors, windows, four existing-to-new connection objects, site, parcel, five parking zones and 225 parking-bay objects.

The model is exported as canonical JSON, object and relationship registers, SVG plans, an HTML model browser, DXF and OBJ/MTL. Its SHA-256 fingerprint is injected into the model-driven drawings and reports production run. Independent downstream geometry authoring is prohibited by the dependency map.

The model remains a concept model. Professional evidence blockers REQ-102, REQ-103, REQ-104, REQ-105, REQ-106 and REQ-108 remain open.
