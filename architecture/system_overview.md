# Phoenix System Overview

Phoenix combines the Brewster Engineering Wizard, BAOEES workflows and the
Phoenix Core into one repository and one operating model.

Current foundation:

- BB1–BB8: foundation, adapters, development console and runtime orchestration
- BB9: Digital Twin Core Engine
- BB9A: Phoenix Knowledge Base and Phoenix Build System

Planned integrations include QGIS, OpenSees and CalculiX.
