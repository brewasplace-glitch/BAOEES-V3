# PEK Mathematics Wave 1 v1.0

This release implements PEK-MATH-0001 through PEK-MATH-0025.

Implemented capabilities:

- deterministic arithmetic;
- powers and roots;
- minimum, maximum and clamping;
- arithmetic and weighted means;
- percentages and percentage change;
- factors, margins and utilization;
- tolerance-based comparison;
- decimal and increment rounding;
- normalization and linear interpolation;
- dot product, vector magnitude and vector normalization.

Invalid mathematical domains, zero denominators, incompatible vector lengths,
empty inputs and non-finite values are rejected explicitly.
