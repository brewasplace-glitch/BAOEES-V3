# PEK-12 Steel Design Engine Wave 1 v1.0

PEK-12 introduces 39 standard-neutral SI-based steel-design
primitives covering material mechanics, section properties, member stability,
resistance, bolted and welded connections, serviceability and fatigue.

The engine does not claim compliance with a named design code. Partial factors,
imperfection factors, resistance coefficients, section-class rules and national
annex requirements remain explicit inputs for later code packs.
