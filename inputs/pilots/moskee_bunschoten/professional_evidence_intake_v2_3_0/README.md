# BB35 Pilot 1 professional evidence intake

This directory contains controlled intake channels for REQ-102, REQ-103, REQ-104, REQ-105, REQ-106 and REQ-108.

Do not rename the requirement folders. Each adviser submission requires:

- `submission_manifest.json`;
- an `evidence/` folder containing the signed professional files;
- `project_leader_decision.json` after validation and review.

Files named `*_template.json` are templates only and are never accepted as evidence.
