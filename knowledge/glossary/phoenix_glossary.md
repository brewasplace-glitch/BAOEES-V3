# Phoenix Glossary

**BAOEES** — Autonomous engineering workflow environment integrated into Phoenix.

**Build Block (BB)** — Versioned, validated increment of Phoenix functionality.

**Digital Twin** — Shared project state containing objects, relationships,
metadata, versions and evidence.

**PKB** — Phoenix Knowledge Base.

**PBS** — Phoenix Build System.

**Runtime Orchestrator** — Engine coordinating execution, dependencies and events.
